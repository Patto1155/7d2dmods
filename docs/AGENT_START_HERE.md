# Agent Start Here

This repo is intentionally organized so an agent can find the important pieces quickly.

Read order:

1. `docs/REPO_MAP.md`
2. `mods/AutoForge/README.md`
3. `mods/AutoForge/ModInfo.xml`
4. `mods/AutoForge/Source/AutoForge.csproj`
5. `mods/AutoForge/Source/AutoForgeMod.cs`
6. `mods/AutoForge/Source/Blocks/AutoForgeBlock.cs`
7. `mods/AutoForge/Source/Network/ConduitNetwork.cs`
8. `docs/LESSONS_LEARNED.md`

What this repo is for:
- preserve the current AutoForge codebase
- keep a clean place for notes and future redesigns
- make it easy to add new 7 Days to Die mods without rediscovering the whole layout each time

Do not waste time scanning generated build artifacts:
- ignore `obj/`
- ignore compiled DLL/PDB outputs
- ignore scratch inspection scripts
