# Lessons Learned

This file is for post-migration notes about what made the first implementation easy or painful.

## Good things to preserve
- Vanilla prefabs for workstation / conduit blocks kept the asset burden low.
- Small number of source files made the first pass understandable.

## Pain points to capture later
- API field names that were not verified at the time.
- Multiplayer sync assumptions.
- Block / recipe / UI relationships that were awkward to debug.
